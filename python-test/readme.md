# Python: автотест подключения к БД

Автотест на Python, который проверяет подключение к бд и роботоспособность запроса. В качестве СУБД используется PostgreSQL.

## Инстркуция

```
    python3 -m venv .venv

    source .venv/bin/activate

    pip install -r requirements.txt
```

В файле conftest.py введите свои значения в следующие поля:

    - host
    - port
    - dbname
    - user
    - password

## Реализация

В файле test_db.py реализовано две проверки. 

Первый тест проверяет, что соединение с бд открыто.

Второй тест выполняет запрос `SELECT now()`, проверяет наличие результата и убеждается, что возвращаемое значение имеет тип datetime.

## Запуск


```
    pytest -v test_db.py
```
